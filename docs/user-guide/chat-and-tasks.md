# 日常对话与任务

[手册首页](README.md) · [命令速查](commands.md)

## 选择项目和会话

私聊直接发任务；群和话题群默认需要 @机器人。图片和文件可以直接发送，Bridge 会下载到运行机器上交给 Agent。

每个聊天、话题有自己的会话。路径指 Bridge 运行机器上的目录：

```text
/cd /absolute/path/to/project
/ws save project
/ws list
/ws use project
```

`/cd`、`/ws use` 会切换工作目录并重置当前会话；`/ws remove project` 只删除命名绑定，不删除项目文件。工作目录是 Agent 的当前目录，实际可访问范围由权限模式决定。

`/new` 或 `/reset` 开始新会话；`/resume` 选择同 Agent、工作目录及权限模式兼容的历史会话。Claude 和 Codex 的原生会话不能直接互相恢复。`/status` 查看当前使用的会话和模型。

## 任务运行中补充要求

直接在同一话题发送补充文字，例如“只检查 dev 分支，先不要改文件”。

| 接入方式 | 补充文字如何处理 |
| --- | --- |
| Codex app-server | 接收进当前回合 |
| Claude Code 双向输入 | 接收进当前进程和会话，在能够处理时纳入 |

“已送入当前任务，等待模型处理”表示输入接口已经接收，尚不表示要求已经执行。收到“送达未知”时不要立刻重复提交可能有副作用的任务，先核对当前任务进展。普通任务中的附件和卡片回调仍走队列。

Codex 统一通过 `app-server` 开启双向输入，已验证 CLI 为 0.162.1；`exec` 后端已移除。已有配置若显式设置了 `transport = "exec"`，需在对应的 `[agents.codex.launch]` 或 `[profiles.<name>.launch]` 中改为 `"app-server"`，将显式为 `true` 的 `ignoreUserConfig`、`ignoreRules` 改为 `false`，然后重启 profile。Claude 双向输入已验证 CLI 为 2.1.302，升级实际调用的 CLI 并加载新版 Bridge 即可。完整配置边界见 [Agent 执行契约](../agent-execution.md)。

## 旁问

```text
/btw 刚才提到的 pipeline 是什么意思？
```

旁问需要已经建立主会话。它使用主会话保存的上下文和自己的旁问历史，在同一话题单独答复。旁问答复不会自动导入主任务；需要主任务采用它时，可以明确引用或复述相关结论。

## 停止任务

`/stop` 停止当前聊天任务，也会取消排队输入及旁问；它不撤销已经完成的操作。`/new`、切换目录等操作也会中断当前任务。

会话助理和盯盘任务在工作台管理，普通聊天的 `/stop` 不控制它们。对应停止方式见[盯盘与任务来源](monitoring.md)。

## 一次性限时任务

发送 `/run` 打开表单，填写任务、截止时间、时区、安全余量和本次模型。提交后会出现预览，核对日期与强制停止时间并确认后才启动。

也可以先生成命令预览：

```text
/run --until 2h --tz Asia/Shanghai --margin 5 -- 检查当前项目并保存问题清单
/run status
/run stop
```

截止时间可以是时长、下一次指定钟点或带时区的完整日期。默认安全余量为 5 分钟：截止 01:00 时，强制停止时间为 00:55，提示 Agent 提前收尾。队列等待也计入固定截止时间；中途补充不会延长时限。强停前不保证一定生成总结。

限时任务只执行这一次；停止、到期、失败或 Bridge 重启后不会自动续跑。`/run defaults` 保存以后创建任务时使用的默认参数，不会创建每日定时任务。限时任务内不支持的附件等输入会明确拒绝，不会排到截止时间之后执行。

Linux 的进程树终止有进程测试覆盖；macOS / Windows 的限时终止实现尚未实机验收。更完整的时间和模型语义见[中文 README](../../README.zh.md#一次性限时任务)。

## 回复显示和临时错误

默认使用飞书原生 COT 的简略模式展示过程，无需手动开启；在 `/config` 可以改为详细或关闭，已有的显式选择会保留。消息卡片或纯文本控制最终答案的样式。首次创建 COT 失败时，本轮会提示一次异常回退；创建成功后更新失败只切换进度显示，不额外发消息，最终答案仍单独发送。

普通任务遇到可恢复的 429 限流时，Bridge 会在 Agent 自身重试后按 30、60、120 秒退避；连续无进展最多三次，有效输出会重置计数。额度耗尽、授权错误、无法安全恢复的会话或送达未知的输入不会盲目重跑。可随时用 `/stop` 取消等待。
